
🧮 Pastel Calc

A clean, modern, soft-UI calculator web application styled in a calming pastel palette. Built entirely with vanilla HTML, CSS, and JavaScript—no frameworks or external dependencies required.

📸 Preview

✨ Features

Soft Aesthetic Design: Palette featuring soft blush pink, mint green, lavender, and cream accents.

Responsive & Centered Layout: Clean card design that scales smoothly across mobile and desktop viewports.

Standard Operations: Addition (+), Subtraction (-), Multiplication (*), Division (/), and Percentage (%).

Input Controls: Full clear (C) and single-character backspace (⌫) capabilities.

Zero Dependencies: Pure vanilla JavaScript logic and custom styling.

🛠️ Tech Stack

HTML5: Semantic element structure for display screen and control grid.

CSS3: Custom properties (CSS variables), Flexbox/Grid layouts, soft elevation shadows, and smooth hover/active state transitions.

JavaScript (ES6+): Pure DOM manipulation, real-time input parsing, and arithmetic expression evaluation.
